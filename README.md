# School Map

Это интерактивная карта различных школ москвы.
Программа предоставляет большой список возможностей, вплоть до создания друзей
или просмотра местоположения камер на карте школы!

# Установка
## Использование готовых бинарных файлов (рекомендуется)
Откройте **"Релизы"** на странице проекта. Там открой страницу последнего
актуального релиза. Ниже будет список файлов под разные ОС и архитектуры.
Выберите тот файл, который подходит вам. При необходимости, сверьте контрольные
суммы файлов.

## Сборка при помощи Make
Для данной сборки необходимо установить утилиту [GNU/Make](https://www.gnu.org/software/make/).
и установить собрать проект с помощью неё.

Установка:
1. Установите [Python](https://www.python.org/). При установке нажмите галочку: `Add Python executable to Path`.
2. Установите [GNU/Make](https://www.gnu.org/software/make/).
3. Скачайте [проект](https://github.com/Salmon-bit/School-Map/archive/refs/heads/main.zip) и разархивируйте его.
4. Откройте терминал в папке с проектом.
5. Выполните команду: `make build`. Программа сама установит и настроит все зависимости.
6. После этого в директории проекта появится исполняемый файл `School map`.
7. Запустите файл.

Программа установлена! При желании можете запустить `make clean` для очистки проекта или, скопировав
исполняемый файл в другую директорию, удалить папку проекта.

## Сборка из исходников
Для данной сборки необходим [Python](https://www.python.org/) и [PIP](https://pypi.org/project/pip/).

Установка:
1. Установите [Python](https://www.python.org/). При установке нажмите галочку: `Add Python executable to Path`.
2. Скачайте и распакуйте [архив](https://github.com/Salmon-bit/School-Map/archive/refs/heads/main.zip) проекта.
3. Откройте терминал в директории проекта.
4. Выполните в терминале: `python -m venv .venv`.
5. В зависимости от вашей ОС и оболочки консоли выполните:
   - Если у вас *Windows*:
   - - Выполните в терминале: `.\.venv\Scripts\activate.bat`, если вы открыли *CMD*, или `.\.venv\Scripts\activate.ps1`, если вы открыли *Power Shell*.
   - Если у вас *Unix-подобная система*:
   - - Выполните в терминале `source ./.venv/bin/activate`. Расширение исполняемого файла зависит от оболочки консоли, которую вы используете.
6. Выполните в терминале: `pip install --upgrade pip`.
7. Выполните в терминале: `pip install -r requirements.txt`.
8. Выполните в терминале: `pip install pyinstaller`.
9. Выполните в терминале: `pyinstaller -Fw -n "School map" main.py`.
10. Откройте каталог `dist`.
11. Там находится исполняемый файл `School map` собранный под вашу систему.
12. В зависимости от вашей ОС выполните следующие действия:
    - Если у вас *Unix-подобная* система:
    - - Выполните в терминале: `chmod +x School\ map`. Предварительно открыв терминал в директории `dist`.
    - Если у вас *Windows*:
    - - Просто запустите исполняемый файл!

На этом сборка закончена. Можете скопировать исполняемый файл в любую директорию и использовать его. При желании, вы можете удалить папку с проектом.

# Использование программы
## Регистрация и вход в систему
Запустите главный исполняемый файл. Перед вами появится окно, содержащие две кнопки: *Вход* и *Регистрация*. Если вы в первый раз запустили программу,
Наджмите на кнопку *Регисрация*, иначе - на кнопку *Вход*.

### Регистрация
После нажатия кнопки регистрации, перед вами откроется еще одно окно с фоомой реистрации. Заполните все его поля, согласно критериям и выберите школу,
карту и учеников которой вы хотите отслеживать.

#### Критерии регистрации
*Пароль*
 - Пароль должен содержать не менее 8 символов

*Почта*
 - Почта должна быть уникальна
 - В почте должен присутствовать символ `@`.

*Имя пользователя*
 - Имя пользователя должно быть уникально
 - Имя пользователя должно быть от 3 до 32 символов в длину.

Для просмотра введенного пароля, необходимо нажать на кнопку, справа от поля ввода пароя.

После заполнения всех полей, нажмите кнопку *Зарегистрироваться*
Если появилось уведомление о успешной регистрации, закройте окно с формой и переходите ко входу в систему.
Если же появилось уведомление об ошибке, выполните требования, которые описывает уведомление и повторите регистрацию.

### Вход
После регисрации, вы можете войти в систему. Откройте начальное окно и нажите кнопку *Вход*. Перед вами появится еще одно окно с формой входа.
Заполните все поля, согласно их описанию. В поле *Данные для входа* можно вписать как имя польщователя, так и почту, указанную при регистрации.

Нажмите кнопку *Войти*.
При успешной авторизации, появится уведомление, сообщающее об этом. Нажмите *OK*
Если авторизация завершилась не успешно, исправьте введенные вами данные и повторите процедуру входа в программу.

## Главное окно
### Верхнее меню
#### Друзья
В программе реализована система друзей. Друзей можно добавлять используя Идентификатор польщователя, E-Mail пользователя и имя пользователя.
Также можно посмотреть добавленных друзей либо через меню, либо используя комбинацию клавиш `Ctrl-F`.
Добавить друга по идентификатору пользователя можно, используя комбинацию клавиш `Ctrl-I`.

#### Школа
В программе можно посмотреть учеников, учащихся в школе либо через меню, либо используя комбинацию клавиш `Ctrl-S`.

#### Расписание
В программе можно добавлять, удалять и изменять расписание.

#### Программа
Во вкладке *Программа* представлены различные функции.
* Справка - Открывает справку по программе
* Создатели - Показывает разработчиков программы
* Информация о пользователе - выводит всю техническую информацию о пользователе (ID, Email, Имя пользователя, Школа)
* Пользовательское соглашение - Открывает пользовательское соглашение
* Лицензия - Открывают лицензию, под котрой распространяется данное ПО
* Выход - Выходит из программы
Также если вы убрали галочку при входе "*Показывать это окно при старте*" у вас также будет еще один пункт:
* Показывать окно при старте - При активации, стартовое окно при старте

### Рабочая обасть
Ниже располагается рабочая область. На рабочей обасти отображатются этажи школы, выбранной при регистрации.
На этажах расписаны кабинеты. Также если у вас или ваших друзей есть активное расписание, то на плане школы
будут отображаться их метки.

В рабочей бласти есть кнопки, отвечающие за масштаб:
* Отдалить - уменьшает масштаб
* 1х - приводит масштаб к стандартнуму
* Приблизить - увеличивает масштаб

Еще ниже есть текстовая метка, показывающая масштаб.

## Расписание
Окно редактора распианий делится на 2 области: правая и левая. В левой области расположено само расписание. Распиание групируется
по дням недели (Понедельник, Вторник, Среда, Четверг, Пятница, Суббота). В распиание написаны кабинет, время урока и его название.

### Левая область
Таже в левой области расположены функциональные кнопки:
* Изменить урок - Необходимо выделить урок и нажатьь на эту кнопку. Вас попросят заново ввести название и кабинет проведения урока.
После этого данные обновятся.
* Удалить послений урок - Удаляет последний урок активного дня недели
* Добавить новый урок - Создает новый урок в активном дне недели

### Правая область
В правой области расположены настройки.

* Длительность урока - установите длительность вашего урока в минутах
* Длительность перемены - установите длину **обычной** перемены в вашей школе
* Длительность большой перемены - установите длительность **большой** перемены.
Если в вашей школе не предусмотрена большая перемена, установите тоже значение, что и в обычной перемене.
* Область с флажками - Выберите те уроки после которых у вас **большая перемена**, если в вашей школе нет большой перемены,
можете не опустить этот пункт.

Кнопка сохранить и выйти - сохраняет изменеия и закрывает окно редактора.

При обычном закртии окна, вас уведомят о несохраненных данных. Если вы подтвердите закрытие окна, данные не сохранятся, а если отклоните,
окно не закроется и вы сможете нажать кнопку *Сохранить и выйти* для сохранения и закрытия окна.
