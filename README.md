# School Map

Это интерактивная карта различных школ москвы.
Программа предоставляет большой список возможностей, вплоть до создания друзей
или просмотра местоположения камер на карте школы!

# Установка
## Использование готовых бинарных файлов (рекомендуется)
Откройте **"Релизы"** на странице проекта. Там открой страницу последнего
актуального релиза. Ниже будет список файлов под разные ОС и архитектуры.
Выберите тот файл, который подходит вам. При необходимости, сверьте контрольные
суммы файлов.

## Сборка при помощи Make
Для данной сборки необходимо установить утилиту [GNU/Make](https://www.gnu.org/software/make/).
и установить собрать проект с помощью неё.

Установка:
1. Установите [Python](https://www.python.org/). При установке нажмите галочку: `Add Python executable to Path`.
2. Установите [GNU/Make](https://www.gnu.org/software/make/).
3. Скачайте [проект](https://github.com/Salmon-bit/School-Map/archive/refs/heads/main.zip) и разархивируйте его.
4. Откройте терминал в папке с проектом.
5. Выполните команду: `make build`. Программа сама установит и настроит все зависимости.
6. После этого в директории проекта появится исполняемый файл `School map`.
7. Запустите файл.

Программа установлена! При желании можете запустить `make clean` для очистки проекта или, скопировав
исполняемый файл в другую директорию, удалить папку проекта.

## Сборка из исходников
Для данной сборки необходим [Python](https://www.python.org/) и [PIP](https://pypi.org/project/pip/).

Установка:
1. Установите [Python](https://www.python.org/). При установке нажмите галочку: `Add Python executable to Path`.
2. Скачайте и распакуйте [архив](https://github.com/Salmon-bit/School-Map/archive/refs/heads/main.zip) проекта.
3. Откройте терминал в директории проекта.
4. Выполните в терминале: `python -m venv .venv`.
5. В зависимости от вашей ОС и оболочки консоли выполните:
   - Если у вас *Windows*:
   - - Выполните в терминале: `.\.venv\Scripts\activate.bat`, если вы открыли *CMD* или `.\.venv\Scripts\activate.ps1` если вы открыли *Power Shell*.
   - Если у вас *Unix-подобная система*:
   - - Выполните в терминале `source ./.venv/bin/activate`. Расширение исполняемого файла зависит от оболочки консоли, которую вы используете.
6. Выполните в терминале: `pip install --upgrade pip`.
7. Выполните в терминале: `pip install -r requirements.txt`.
8. Выполните в терминале: `pip install pyinstaller`.
9. Выполните в терминале: `pyinstaller -Fw -n "School map" main.py`.
10. Откройте каталог `dist`.
11. Там находится исполняемый файл `School map` собранный под вашу систему.
12. В зависимости от вашей ОС выполните следующие действия:
    - Если у вас *Unix-подобная* система:
    - - Выполните в терминале: `chmod +x School\ map`. Предварительно открыв терминал в директории `dist`.
    - Если у вас *Windows*:
    - - Просто запустите исполняемый файл!

На этом сборка закончена. Можете скопировать исполняемый файл в любую директорию и использовать его. При желании, вы можете удалить папку с проектом.
